# ESP32 Air Quality & Environmental Monitoring System

A simulated ESP32-based air-quality and environmental monitoring system developed using Wokwi.

## Project Status

Under development.

## Planned Measurements

- Temperature
- Humidity
- Atmospheric pressure
- PM1.0
- PM2.5
- PM10

## Planned Technologies

- ESP32
- C++
- Wokwi
- I2C
- UART
- OLED
- Wi-Fi
- HTTP/JSON
